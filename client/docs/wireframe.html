Content hierarchy

What each frame holds, in reading order from top to bottom.

1 Start

  1. Headline and one line on what the app does
  2. Meal choice: Breakfast, Lunch, Dinner, All day (Lunch preselected)
  3. Start, the only main action

2 Question

  1. Session line: date, meal, number of dishes
  2. Progress: question number and a bar
  3. The question
  4. Six answers, most positive at the top, "Not sure" last
  5. Secondary actions at the bottom: Back, Just recommend something

3 Guess: one dish

  1. Session line
  2. Prompt
  3. Card: the dish, then each cafeteria with meal and price
  4. Yes (main action), then No
  5. Back at the bottom

4 Guess: a kind of dish

  1. Session line
  2. Prompt
  3. Card: the group name first, then one example dish with its cafeteria, then other dishes in the group
  4. Yes (main action), then No
  5. Back at the bottom

5 Recommendation

  1. Session line
  2. Closing line
  3. Card: the dish, its full menu name if different, where to get it
  4. Start over, the only action

6 Nothing to recommend

  1. Session line
  2. Headline
  3. The reason
  4. Start over, the only action

7 Request failed

  1. Banner at the top: what went wrong, with Try again beside it
  2. Below it, the screen the user was on, unchanged
